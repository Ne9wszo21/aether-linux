# Aether Linux



aether, based on arch linux, begginer friendly ui and bloat free.

---

## Features

| | |
|---|---|
| **material 3 (i guess?)** | idk man |
| **arch underneath** | rolling releases, keeping you up to date. |
| **guided install** | wipe the drive or install alongaide with windows. |
| **UEFI + GRUB** | uefi boot with grub|
| **easyboot (coming soon)** | welcome app that setup for you.|
| **no bloat** | unrequired packages will not be installed. |

## install

requirements: a UEFI system and at least 8 GB of free disk space and 2GB of ram. (BIOS coming soon.)

```sh
#write the iso with rufus, ventoy, woeusb-ng or balenaetcher then open a terminal by CTRL+ALT+T then type:
sudo aether-installer
#it should open a window.
```
